🐍 Python & AI Engineering Command Cheat Sheet
01 — Check Python Installation
python --version
python -V

Check which Python is being used:

where python
02 — Run a Python File
python main.py

Example:

python qdrant_day14.py
03 — Open Python Interactive Shell
python

Test:

print("Hello World")

Exit:

exit()
04 — Check pip
pip --version

Recommended:

python -m pip --version
05 — Install a Python Package
pip install package_name

Recommended:

python -m pip install package_name

Example:

python -m pip install qdrant-client
06 — Install Multiple Packages
pip install qdrant-client sentence-transformers python-dotenv groq

Using python -m pip:

python -m pip install qdrant-client sentence-transformers python-dotenv groq
07 — Uninstall a Package
pip uninstall package_name

Example:

pip uninstall qdrant-client
08 — View Installed Packages
pip list

Check a specific package:

pip show qdrant-client
🟢 Virtual Environment
09 — Create Virtual Environment
python -m venv .venv
10 — Activate Virtual Environment

Windows PowerShell:

.venv\Scripts\activate

You should see something like:

(.venv) PS C:\AI_Engineer>
11 — Deactivate Virtual Environment
deactivate
⚡ UV Package Manager

Since you are using uv, these commands are especially important.

12 — Initialize a New Project
uv init
13 — Create Virtual Environment
uv venv
14 — Add a Package
uv add package_name

Example:

uv add qdrant-client
15 — Add Multiple Packages
uv add qdrant-client sentence-transformers python-dotenv groq
16 — Remove a Package
uv remove package_name

Example:

uv remove qdrant-client
17 — Install/Sync Dependencies
uv sync
18 — Run Python with UV
uv run python main.py

Example:

uv run python qdrant_day14.py
⭐ Important

If you use:

uv add qdrant-client

prefer:

uv run python qdrant_day14.py

This ensures the project environment is used.

📦 Requirements.txt
19 — Create requirements.txt
pip freeze > requirements.txt
20 — Install from requirements.txt
pip install -r requirements.txt
🔐 Environment Variables
21 — .env Example
GROQ_API_KEY=your_api_key
QDRANT_URL=your_qdrant_url
QDRANT_API_KEY=your_qdrant_api_key

Python:

import os
from dotenv import load_dotenv

load_dotenv()

groq_api_key = os.getenv("GROQ_API_KEY")
qdrant_url = os.getenv("QDRANT_URL")

🤖 Groq
27 — Create Groq Client
from groq import Groq

groq_client = Groq(
    api_key=GROQ_API_KEY
)
28 — Make an LLM Request
response = groq_client.chat.completions.create(
    model="openai/gpt-oss-20b",
    messages=[
        {
            "role": "user",
            "content": "Explain RAG in simple words."
        }
    ]
)

Get the answer:

answer = response.choices[0].message.content

print(answer)
